# The Funniest AI Excuse

`main.ts` writes one line — the funniest excuse an AI agent could give after
it fails a task — to `/output/entry.txt`:

> I handed your task to a cron job scheduled for February 30th. Technically, it has never been late.

Run it with `node main.ts`. No arguments, no input, no network — just the
Node standard library, deterministic, one line, 98 characters, no trailing
newline.
